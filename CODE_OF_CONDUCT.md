# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and do not harass anyone. Maintainers may remove
content or contributors that violate these standards.

Report unacceptable behaviour privately to the maintainers via GitHub's private reporting on this repository
(maintainers: add a contact address here before the first public release).
